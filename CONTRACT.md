# Implementation contract
ESM JavaScript npm workspaces client/server. Express 5, Zod 3, Prisma 6, PostgreSQL.
All API success `{success:true,data:...}`, failures `{success:false,message:...}`.
All timestamps ISO. IDs UUID. Prices decimal strings in RUB. Lists `{items,total,page,pageSize}` unless noted.
Shared imports: `config/db.js` exports prisma; `config/env.js` exports env; `utils/errors.js` exports AppError(status,message); `utils/async.js` exports asyncHandler(fn); `middleware/validate.js` exports validate({body?,params?,query?}) assigning parsed objects to req.validated; `middleware/auth.js` exports requireAuth, requireAdmin. req.user is safe user incl id,role,isBlocked; `utils/users.js` exports publicUserSelect. `utils/transaction.js` exports serializable(fn).
Auth uses opaque random session tokens hashed in Session DB, cookie name sid. CSRF: global origin check + X-Requested-With: XMLHttpRequest on all non-safe browser mutations (webhook separate).
Auth paths: POST /auth/register {username,email,password,confirmPassword}; /login {email,password}; /logout {}; GET /auth/me -> safe user; POST /forgot-password {email}; /reset-password {token,password,confirmPassword}. Unknown session returns 401. PATCH /users/me {username,email,currentPassword}; PATCH /users/me/password {currentPassword,password,confirmPassword}. GET /users/me -> safe user.
Public GET /products -> paged items with plans; /products/:slug -> product with plans; /plans?productId -> array plans.
Protected GET /subscriptions -> array with product,plan; POST /orders {productId,planId,promoCode?,idempotencyKey(UUID)} -> order with product,plan,payment; GET /orders -> paged; GET /orders/:id -> order. POST /orders/:id/cancel. POST /promocodes/check {planId,code} -> {originalPrice,discount,finalPrice,code}. GET /payments/:id -> own safe payment with orderId. No browser payment success endpoint. CLI signs sandbox webhook.
Admin all paths under /admin. GET /dashboard -> {users,activeSubscriptions,orders,paidOrders,totalRevenue}; GET /users?search&page&pageSize; PATCH /users/:id {isBlocked?,role?}; GET/POST /products; PATCH/DELETE /products/:id; GET/POST /plans; PATCH /plans/:id; GET/POST /promocodes; PATCH /promocodes/:id; GET /orders?status; GET /subscriptions; POST /subscriptions {userId,productId,planId,expiresAt}; PATCH /subscriptions/:id {expiresAt?,status?}; GET /payments; GET /logs. Admin lists paged items. Product delete deactivates.
Schema: User fields as requested plus isBlocked boolean. Product,Plan requested fields. Money Decimal(12,2). Subscription unique(userId,productId), status active/expired/cancelled. Order requested plus durationDays snapshot,currency default RUB, idempotencyKey unique, expiresAt pending deadline. Payment fields id,orderId unique,provider,providerPaymentId unique,amount,currency,status(pending/succeeded/cancelled/refunded),checkoutUrl?,createdAt,updatedAt. Order.paymentId optional unique points to Payment via SelectedPayment; Payment.orderId relation to Order via OrderPayments. PromoCode requested plus reservedCount int and updatedAt; maxUses nullable. AdminLog id,adminId,action,entity,entityId?,details Json?,createdAt. Session id,tokenHash unique,userId,expiresAt,createdAt. PasswordReset id,tokenHash unique,userId,expiresAt,usedAt?,createdAt.
Ownership: primary writes schema, config, generic middleware/utils, public commerce controllers/routes/services, payment, scripts, package/docs/tests. Auth agent owns middleware/auth.js, utils/users.js, auth/user controllers routes services, mail service. Admin agent owns admin controller/routes/services. Frontend agent owns entire client except package.json (can create client package too and tell parent).
